## 本次发现并修复的运行环境问题

Codex 沙箱原本只提供系统 PATH，在这台 Mac 上解析到依赖 Xcode Command Line Tools 的系统 Python，导致代码虽已修改但测试无法执行。现在使用正在运行的平台后端所属的基础 Python 发行目录：将其 bin 加入沙箱 PATH，并仅授予该发行目录读取权限。不继承用户 PATH，不开放整个 home、后端虚拟环境或原项目，也不开放网络。

真实沙箱重测：5 项测试通过；读取沙箱外认证文件的探针仍返回 PermissionError，未读取或输出认证内容。边界测试覆盖根目录、缺失运行时、指向目录外的解释器和恶意 PATH。

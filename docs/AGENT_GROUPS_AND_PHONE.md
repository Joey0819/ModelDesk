# 独立 Agent 项目群与手机访问

ModelDesk 2.5 在同一项目群中保留两种明确的工作方式：模型讨论，以及真正读写隔离代码副本的 CLI Agent。讨论模型和执行器分别显示，避免把某个成员的显示名称误当成实际运行引擎。

## 执行、审查、审批

1. 在共享项目入口关联一个已有提交、没有未提交改动的 Git 仓库。普通资料项目仍可讨论；执行代码需要 Git 基准，不自动初始化用户目录。
2. 打开项目群，切换到「执行任务」，@ 指定本群成员，选择已登录的 Codex 或 Claude Code，填写任务并开始。
3. 每个任务复制当前提交中允许的文件到独立副本。进度、真实进程输出、退出状态、改动和基准提交保存在本机；两个任务可以并行，其余排队。
4. 代码任务结束后，选择另一位成员进行审查。默认「成员模型」会实际调用该成员的模型，例如 Gemini；也可以选择已登录的只读 CLI 执行器。审查绑定该任务的确切补丁哈希，读取冻结后的成果，不读取继续变化的原项目。模型审查收到完整补丁及有明确截断标记的文件上下文，没有执行工具。
5. 查看实际改动和审查文字，创建审批卡片。只有你点击「批准并合入本地项目」，才会向登记仓库执行 Git fast-forward。拒绝不修改项目。

审批卡片绑定项目、群、任务、审查、补丁哈希、基准提交、目标分支和项目目录。原项目有未提交文件，或者分支、路径、提交发生变化时，旧审批不能合入。先使用独立临时索引生成候选提交，再由 Git 合入；不会把用户暂存文件夹带入提交。此按钮目前只合入本地仓库，**不会推送，也不会合并 GitHub PR**。

审查输出是 Agent 的意见，不等于 CI 通过。界面不从“看起来没问题”等自然语言猜出通过标志。真实进程成功结束表示取得完整执行产物，不代表代码已正确。请查看执行记录和实际审查结果。

## 执行边界与恢复

- Codex 使用官方 CLI 非交互 JSON 事件和操作系统权限配置，命令只可读写隔离工作区，不能写 `.git` 或访问原仓库；命令网络关闭。模型连接仍由 CLI 使用原有登录。
- Claude Code 使用支持 `--restricted`、`--safe-mode` 的版本，只开放所需文件工具；关闭终端、浏览器、MCP、项目 hooks。它能编辑文件，但这条执行路径不运行项目测试。
- 不复制原仓库的 Git 历史、远程地址、凭据、用户 CLI 配置、项目代理配置或链接文件。不继承工作台的 API 密钥。被排除文件和大小限制随任务记录。
- 代码任务和审查均有超时、取消与退出记录。取消时清理已跟踪的子进程，包括另建会话的工具进程；使用进程创建时间避免误杀被复用的 PID。服务重启把未完成任务标为中断，不自动重发指令、继续执行或合并。
- 原项目较大、包含特殊链接或源码执行需要网络安装依赖时，任务会说明限制；不会自动解除限制。
- Muse 仍是单独的原生窗口执行器。它需要当前 Mac 的辅助功能授权，读取回复后可显式交给群讨论。该系统权限状态和 CLI Agent 登录状态独立。

## 手机访问

1. Mac 和手机都登录同一个 Tailscale 网络，在 Mac 打开 Tailscale 连接。
2. ModelDesk 左侧打开「手机连接」，启动私有入口。它只使用 Tailscale Serve 的 HTTPS 8443 端口；该主机名需专用于 ModelDesk 的 HTTPS 服务，已有冲突时拒绝启用并保留原配置。浏览器 Cookie 不按端口隔离，因此不能与同一主机名上的其他 HTTPS 应用共用。
3. 在 Mac 生成一次性配对码，手机浏览器打开显示的 HTTPS 地址，在页面中输入配对码。配对码五分钟内有效，只能用一次。
4. 手机可以查看项目、群历史和成果，上传图片/文件，发消息、派发 Agent、停止任务，并对实际审批卡作出决定。浏览器可添加到主屏幕作为快捷入口。
5. 结束使用可退出登录；Mac 上可以撤销单台设备、撤销全部设备或关闭入口。

手机访问需要 Mac 保持开机、网络可用且 ModelDesk 服务运行。Mac 休眠或服务停止时，手机不能代替它执行任务。原生文件夹选择、启动其他本机应用、Muse 原生窗口派发、执行原生 SDK Python 脚本和访问管理需要在 Mac 操作。手机上传是浏览器选择自己的文件，不会自动扫描手机或电脑目录。

入口仅对 Tailscale 私有网络开放，不使用公网 Funnel。网关绑定 `127.0.0.1:8766`，原 API 仍绑定 `127.0.0.1:8001`。网关提供同源前端/API/SSE，每个 API 请求都检查会话；原始 API 不暴露到局域网。12 小时会话以 Secure、HttpOnly、SameSite=Strict Cookie 保存，数据库只保存令牌哈希。配对码不放在 URL、日志或 localStorage；撤销后现有流式连接也会停止继续传输。

## 架构与验证

- `backend/group_tasks.py`：CLI 能力检测、快照、进程调度、冻结补丁、审查和恢复。
- `backend/group_approvals.py`：人工决定、精确证据绑定、临时 Git 索引、受控本地合入。
- `backend/remote_access.py`：配对/会话、Host/Origin 校验、上传和流式代理、私有入口生命周期。
- `frontend/src/components/GroupAgentTasks.jsx`：按群保存草稿、任务/审查/审批卡片。
- `frontend/src/components/RemoteAccessPanel.jsx`：Mac 入口设置和设备管理；远程页面有独立配对界面。
- `scripts/modeldesk_remote.py`：本机命令行查看、开启、关闭或撤销访问。

基础验证运行 `.venv/bin/python scripts/verify_modeldesk.py`，重新构建 `.venv/bin/python scripts/package_modeldesk.py`。真实 Agent 验收使用自建小型 Git 项目；不在用户原项目上做演示性合并。手机端最终网络连通性需在实际手机检查，浏览器窄屏和本机 HTTPS 测试不能替代这一项。

2026-10-13 的实际验收已从桌面界面派发 Codex `gpt-6.1-sol`，在独立副本新增 Bash 脚本并实际跑过两个用例，再由 Gemini `gemini-3-flash` 审查确切补丁，通过审批卡合入演示仓库。合入后两个用例再次通过，下载记录与后台导出一致。当前 Claude Code 的受限执行环境未取得可用登录，界面如实禁用；普通 CLI 登录状态不能替代受限执行器的能力检查。

同日通过真实 iPhone 的 Safari 完成 HTTPS 配对，读取已有项目群，并 @ 审查员发起一次实际 Gemini 补丁审查，后台记录为完成且绑定原补丁哈希。手机会话在用户同意后保留 12 小时。另验证了未登录拒绝、配对码单次使用、会话撤销、CSRF 拒绝和实际 SSE 事件。Mac 访问自身 Tailscale HTTPS 地址的诊断曾失败，但实际 iPhone 已能访问；没有据此改动用户的 Shadowrocket 路由。手机测试也修复了 iOS 自动替换短横线导致配对码失效的问题。
